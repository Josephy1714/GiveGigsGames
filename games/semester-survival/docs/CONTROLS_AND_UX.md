# Controls and UX

## Desktop
- A / D or Left / Right: move/turn.
- W / Up / Space: jump only where supported.
- S / Down: crouch/slide only where supported.
- Shift: sprint while held; consumes energy where appropriate.
- E / Enter: interact with focused nearby person/object.
- Tab: open/close student phone.
- Esc: pause/back.
- Mouse: select UI, dialogue and map destinations.

Inputs are context-sensitive. A movement key must not trigger a world action while dialogue or phone UI is active.

## Mobile
- Swipe left/right: movement or route change where supported.
- Swipe up: jump where available.
- Swipe down: crouch/slide where available.
- Tap a clearly indicated nearby person/object to interact.
- Avoid permanent oversized virtual joysticks and action buttons. Context prompts may briefly appear near an interactable.

## Priority
1. Active modal, dialogue or phone control.
2. Explicit nearby interaction target.
3. World movement.
4. No action.

## Accessibility
Visible keyboard focus, readable narrow-screen text, icon plus label (not colour alone), reduced-motion option where practical, and safe pause on focus loss.
