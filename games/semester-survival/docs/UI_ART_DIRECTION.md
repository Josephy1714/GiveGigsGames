# UI Art Direction

## Visual language
Premium, restrained student-life interface. Deep ink/navy foundations, warm paper surfaces, limited electric-blue accent and reserved status colours. Display type is for short labels, not body copy.

## HUD
Contextual and minimal: time/day, current objective and one or two relevant condition indicators. Avoid permanently covering the world with arcade panels.

## Student phone
An in-world interface with timetable, messages, tasks/notes, map, money and academic record. Every module reads or updates real game state. Phone screens suspend world input.

## Menus and feedback
Short deliberate transitions with reduced-motion fallback. Menus work with keyboard and touch and have a clear back path. Feedback shows action, result, reason and changed state. Pair icon, label and colour; never show an unverified success tick.
